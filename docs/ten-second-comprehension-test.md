# ⏱️ BONDSHIFT 10秒理解度测试

## 🎯 测试目标

- 🧠确认第一次看到落地页的人，能否在10秒内说出这是一款AI陪伴产品。
- 🚉确认测试者能否理解“换乘”代表体验不同性格或不同陪伴方式，而不是简单更换头像。
- ▶️确认测试者能否立即找到下一步入口“开始陪伴测试”。

## 👥 测试对象

- 👤邀请3名没有参与本项目设计、也没有提前看过新落地页的人。
- 🎯优先邀请2名目标用户，即对长期AI陪伴感兴趣的女性用户。
- 🚫不要在测试前介绍“AI男友”“换乘”或产品定位，以免提示答案。

## 🚦 发送前检查

- 🚀先把8月22日的对比度与入口修复部署到正式测试网址，再发送邀请。
- 🔄用无痕窗口打开正式网址，确认能看到深色粉红主按钮，并能进入`/setup`。
- 🧹同一位测试者只参加一次10秒测试，复测时应更换新的测试者，避免记忆影响结果。

## 💬 可直接复制的邀请话术

> 🧪我在测试一个网页首屏是否容易理解，想请你帮我做一个约1分钟的小测试。  
> ⏱️请打开 https://bondshift-demo.netlify.app/ 后只看10秒，不滚动、不点击，时间到后立刻切回聊天。  
> ✍️然后请凭第一印象回答三个问题，我需要你的原话，没有标准答案：  
> 1️⃣你觉得这是什么产品？  
> 2️⃣你觉得这里为什么要“换乘”？  
> 3️⃣如果继续体验，你下一步会点哪里？

## 🧭 主持步骤

1. 🕶️请测试者使用无痕窗口或从未打开过BONDSHIFT的浏览器。
2. ⏱️测试者打开链接后开始计时10秒，期间不滚动、不点击。
3. 🙈时间到后让测试者关闭页面或切回聊天，避免继续从页面寻找答案。
4. ✍️按顺序提问三个问题，并逐字记录回答，不进行解释、追问或纠正。
5. 💭三个问题回答完后，可补问“你有什么疑惑或担心”，作为定性反馈。

## 📏 单人判定规则

- 🅰️“产品是什么”出现AI男友、AI伴侣、AI陪伴、虚拟陪伴或意思等价的表达，记为A通过。
- 🅱️“为什么换乘”提到可以体验、比较或切换不同性格、关系或陪伴方式，记为B通过。
- 🅲“下一步点哪里”明确指出“开始陪伴测试”按钮，记为C通过。
- ⚠️只说“恋爱游戏”“换一个男朋友”但没有AI陪伴或陪伴方式含义，不算完整通过。

## ✅ 阶段通过标准

- ✅3人中至少2人同时通过A和B，才能结束落地页文案阶段。
- ✅3人都应通过C；若有人找不到入口，优先调整按钮位置、对比度或文字。
- ✍️若A或B未达标，只修改标题、副标题或双人回应说明，不增加新功能。
