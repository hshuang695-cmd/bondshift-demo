# 🧪 BONDSHIFT 公开可用性测试脚本

📅计划测试日期：2026年8月29日至8月30日。  
⏱️单次测试时长：约10至15分钟。  
👥目标样本：8至12人，其中至少5人为目标女性用户。

## 👥 测试者构成

- 👩5至7名18至30岁女性目标用户。
- 🧑1至2名不了解项目的普通用户。
- 🎓1至2名具有产品、设计、心理或学术背景的用户。

## 📣 招募文案

> 💝我正在优化一款叫BONDSHIFT的AI陪伴产品。  
> 🚉它通过不同AI人格和“关系换乘”帮助用户发现自己偏好的陪伴方式。  
> 🧪我计划在8月29日至30日进行一次约10分钟的线上体验测试。  
> 📱测试只需要打开网页完成体验，并回答几个简单问题。  
> 🔒测试不会公开聊天隐私，也不需要付费。  
> 🙋如果你愿意参与，请告诉我方便的时间和主要使用设备。

## 🎙️ 开场说明

🧪这次测试评估的是产品，不是测试者本人。  
💬请测试者在体验过程中尽量说出正在想什么。  
🧭当测试者不知道下一步该做什么时，主持人先记录并等待，不要立即提示。  
🔒主持人不得要求测试者输入真实隐私或敏感经历。

## 📌 测试任务

1. 📌请打开网站，并告诉我你认为这个产品是做什么的。
2. 📌请开始体验并完成匹配。
3. 📌请与匹配男友进行至少五轮对话。
4. 📌请体验另一种男友对同一问题的回应。
5. 📌请决定留下还是换乘。
6. 📌请找到并生成关系画像分享卡。
7. 📌请在不真正发送给朋友的情况下说明你是否愿意分享。

## 👀 观察记录

- 👀测试者是否在10秒内理解产品。
- 👀测试者是否能找到开始按钮。
- 👀测试者完成三道题所需时间。
- 👀测试者是否理解匹配理由。
- 👀测试者是否相信AI记住了自己。
- 👀测试者是否理解“换乘”而不觉得只是换皮角色。
- 👀测试者是否担心旧关系或聊天隐私。
- 👀测试者是否主动寻找分享入口。

## ❓结束访谈问题

- ❓哪个环节最吸引你？
- ❓哪个环节最困惑你？
- ❓你是否相信这个角色记住了你？
- ❓你是否愿意第二天继续使用？
- ❓你是否愿意把画像卡分享给朋友？
- ❓“换乘”让你觉得有趣、残忍、轻浮，还是有帮助？
- ❓如果只能保留一个功能，你会保留哪个？
- ❓你认为这个产品与普通AI聊天工具最大的差异是什么？

## ✅ 有效测试判定

✅测试者独立完成或明确放弃核心任务。  
✅主持人记录至少一个行为观察和一个访谈反馈。  
✅测试数据中不保存真实聊天内容。  
✅测试者同意其匿名反馈用于作品集总结。
